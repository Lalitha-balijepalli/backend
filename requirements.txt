# ARCHITECTURE NOTE (why there's no tensorflow/torch/deepface/whisper here):
#
# The original stack ran DeepFace (TensorFlow) and Whisper (Torch) locally.
# Lazy-loading them (only importing on first request, not at startup) fixed
# Railway's health-check timeout, but it could NOT fix Render free tier's
# 512MB memory ceiling: torch + a loaded Whisper model alone use ~490MB by
# themselves, confirmed via production logs showing repeated
# "Ran out of memory (used over 512MB)" kills on the very first real
# request. No amount of code-level optimization closes that gap on a
# 512MB instance.
#
# Fix: emotion detection and transcription now call the Gemini API
# (multimodal) instead of running models locally - see
# app/services/emotion_service.py and app/services/whisper_service.py.
# This removes ~2GB+ of ML dependencies and keeps resident memory in the
# tens of MB, comfortably inside free-tier limits, in exchange for network
# calls to Gemini (which you already had a dependency on) and Gemini API
# usage cost per request.
