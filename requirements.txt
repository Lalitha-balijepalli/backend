# ARCHITECTURE NOTE (why there's no tensorflow/torch/deepface/whisper/genai
# here):
#
# The original stack ran DeepFace (TensorFlow) and Whisper (Torch) locally.
# Lazy-loading them fixed Railway's health-check timeout, but not Render
# free tier's 512MB ceiling: torch + a loaded Whisper model alone use ~490MB
# by themselves, confirmed via production logs showing repeated
# "Ran out of memory (used over 512MB)" kills on the first real request.
#
# That was fixed by moving emotion detection and transcription to a hosted
# API. This went through Google Gemini first, but repeated API-key friction
# and a mid-project model retirement (gemini-2.0-flash -> gemini-3.6-flash)
# led to switching to Groq instead - see app/services/groq_client.py,
# app/services/emotion_service.py, and app/services/whisper_service.py.
#
# Groq's API is OpenAI-compatible, so it's called with plain `requests` -
# no SDK needed, keeping resident memory in the tens of MB.
# ============================================================================
